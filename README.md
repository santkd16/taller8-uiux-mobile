# Taller 8 · UI/UX móvil

Sitio estático de apoyo a la exposición de David Santiago Piedrahita Cabezas. `index.html` es el dashboard de presentación; `ejemplos.html` contiene demostraciones interactivas de los cinco ejes del taller.

Abre `index.html` directamente en un navegador o ejecuta `python3 -m http.server 8000` en esta carpeta. No requiere dependencias ni compilación.

Los casos de banca, salud y logística son ejemplos didácticos. Las pantallas de la demo son prototipos locales; no representan pruebas con usuarios, conexión a servicios cloud ni una implementación offline. El informe editable adjunto conserva el desarrollo académico y las referencias completas.

La carpeta `documentos/` incluye el informe editable y la guía original del taller. El dashboard enlaza ambos archivos.
